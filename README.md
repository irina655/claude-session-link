# Claude session link

A single static page that turns a normal https link into a Claude desktop deep link.

Usage: `https://irina655.github.io/claude-session-link/?s=<session id>`

- `s=local_...` opens that local session in the Claude desktop app (`claude://code/continue?session=...`).
- `s=last` opens the most recently active session.

The page holds no data. The session id lives only in the link you share.
